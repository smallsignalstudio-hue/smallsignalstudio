## Act 0 — Babylon (Etemenanki) — **FLAG: needs-doc**

**Status:** No `BABYLON-*` research file in repo. Hooks below are brief, grounded public archaeology / Assyriology consensus — **replace or deepen when dedicated doc lands**.

| Field | Hook |
|---|---|
| **Keep** | **Etemenanki** (“House of the Foundation of Heaven and Earth”) — Marduk’s staged temple-tower in Babylon; Esagila temple complex as sacred ground floor. Nebuchadnezzar II restorations are the usual late Neo-Babylonian face. |
| **7-layer fantasy** | Classical/Herodotean staged tower (often read as **7 terraces** + summit shrine) → game stack: (1) outer approach / canal fringe → (2) **Imgur-Enlil** outer wall → (3) **Nemetti-Enlil** inner wall → (4) Processional Way approach → (5) **Ishtar Gate** choke → (6) ziggurat terrace climb → (7) summit cella / Marduk presence. Koldewey’s excavation: baked-brick core, ~square base classically ~91 m — treat measured numbers as **ARCH ranges**, not tourist “Tower of Babel height.” |
| **Signature towers** | Mudbrick curtain + tower intervals; Ishtar Gate (glazed-brick boss gate + mušḫuššu / aurochs relief language); Processional Way flanks; terrace archer platforms; Esagila precinct wards. |
| **Signature enemies** | Assyrian siege trains (earlier chronology antagonist); Elamite highland raiders; Median/Persian late waves; **Cyrus 539** twin tellings (Opis/Chronicle vs Herodotean river-drain twist — label both). |
| **Myth ultimates** | **Marduk** cosmic order strike / “Enuma Elish” season buff; **mušḫuššu** sacred guardian unit; New Year *akītu* procession temporary lane lock; **Ishtar** war-and-gate aura. |
| **Do-not-assume traps** | Babel Bible story ≠ measured elevation; Hanging Gardens existence/location disputed — atmosphere only; “7 colors like Ecbatana” not Babylon archaeology; Kaynar yağ as default Babylon kit = weak; Nebuchadnezzar ≠ cartoon wizard-king. |
| **Campaign act pitch** | **Act 0 tutorial:** climb and hold the staged mountain of Marduk while walls and gates teach the shared 7-layer grammar every later civ remixes. |

**One-line pitch:** Climb Marduk’s seven-stage ziggurat and learn the game’s keep grammar before empires rewrite it.

## Act 1 — Rome

| Field | Hook |
|---|---|
| **Keep** | **Capitolium / Templum Iovis Optimi Maximi** — three *cellae* (Jupiter / Juno / Minerva); fail = aquila / temple lost. Castrum *principia*/*aedes* is the field-map twin. |
| **7-layer fantasy** | Alesia + castrum stack outward→in: (1) *stimuli* → (2) *lilia* → (3) *cippi* → (4) *fossa* → (5) berm + *vallum* → (6) *lorica*/*pinnae* + mural towers → (7) *principia*/Capitolium. City skins: Servian early / Aurelian late double curtain. |
| **Signature towers** | Scorpio sniper; ballista; onager battery; Aurelian twin-tower enfilade; Juno’s geese stealth detect; *horrea* / aqueduct supports. |
| **Signature enemies** | Gallic warbands; Pyrrhus elephants; Hannibal (elephants + Numidian horse); Parthian horse-archer + cataphract; Alaric “gate opened” twist boss; inverted Roman siege kit (*aries*, *turris*, *testudo*) when player defends. |
| **Myth ultimates** | **Jupiter** triumph lightning / restore-rededicate; **Aquila** legion morale tether; **Mars** sortie rage; Sibylline one-shot strategy card (risk: temple fire burns the deck). |
| **Do-not-assume traps** | “Always boiling oil” as Roman default; every Republican soldier = Marian clone; Capitolium never burns (it did — rebuild cycles are content); ignore auxilia; treat every Germanic foe as the same blob. |
| **Campaign act pitch** | **Act I:** From Servian citadel drills through Alesia engineering school to Aurelian twilight — defend the Capitol while enemies borrow Rome’s own siege book. |

**One-line pitch:** Trap-field castra and Jupiter’s Capitol teach engineering defense against elephants, Parthians, and opened gates.

## Cross-civ design rules (from research index)

1. Every civ remixes the **same 7-layer keep grammar** with ARCH-first stacks; myth sits on layer 7 / ultimates, not fake wall thicknesses.
2. Prefer **dual keeps** when docs prescribe them (military diagram + ideology brand).
3. Tag **FOLK / LIT / SAGA / SPN** content; never let it silently overwrite ARCH chronology.
4. Signature enemies should often be **other roster civs** + era-specific bosses (enables shared assets, rivalry acts).
5. Babylon Act 0 teaches the grammar; **needs dedicated research doc** before vertical slice locks numbers.
