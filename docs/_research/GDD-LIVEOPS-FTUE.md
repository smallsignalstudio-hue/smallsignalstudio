# Live ops, FTUE, onboarding, sezon takvimi

## 1. FTUE (ilk 10 dakika) — kritik

### Hedefler
- 60s içinde ilk kule kurulsun.
- 3 dk içinde ilk wave clear + ödül dopamini.
- 8 dk içinde ilk ★3 veya yakın.
- 10 dk içinde Act 0 Babylon finale soft + Codex 1 sayfa.

### Adımlar
1. **Cold start cinematic** 8s max (Etemenanki siluet) — skippable.
2. Ghost hand: place archer on highlighted plot.
3. Forced teach: upgrade once.
4. Forced teach: barracks block.
5. First leak → explain keep HP (not shame).
6. Early-call intro after wave 4.
7. Victory → name commander → soft reward shower (not 50 currencies).
8. Hub: only 3 buttons visible (Play, Codex, Shop greyed gently).

### Anti-patterns
- Wall of text lore.
- 8 currency explanation.
- Account gate before play (allow guest → later link).

## 3. Live ops takvimi (örnek yıl)

- **Weekly:** Daily challenge set; balance hotfix window.
- **Biweekly:** Mini narrative skirmish.
- **Monthly:** Boss Siege (BTD-like).
- **6–8 weeks:** Battle Pass season (civ theme: “Season of the Masugata”).
- **Quarterly:** New civ act OR major map pack.
- **Yearly:** Anniversary collection.

## 4. Event types

1. Collection event (cosmetic fragments).
2. Boss siege ladder (skill brackets, not P2W power).
3. Guild async fort defense.
4. Double star weekend (careful inflation).
5. Historical anniversary (e.g., museum collab fantasy).

## 6. Accessibility FTUE
