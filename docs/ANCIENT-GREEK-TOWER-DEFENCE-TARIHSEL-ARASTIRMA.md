# ANTİK YUNAN TOWER DEFENCE — Kapsamlı Tarihsel Araştırma Dokümanı

> Bu doküman, "Ancient Greek / Acropolis–Long Walls Tower Defence" (veya "Polis / Makedon / Helenistik Tower Defence") oyunu için toplanan tarihsel, arkeolojik, askerî ve mitolojik malzemeyi içerir. Babil, Roma, Pers, Mısır, **Çin**, **Maya–Mexica** ve **Viking** araştırmalarıyla **aynı formatta** ve **Çin TD Türkçe raporundan bilinçli olarak daha derin** hazırlanmıştır (çok tiyatro: polis rekabeti, Atina deniz imparatorluğu, Sparta/Thebai hegemonya deneyleri, Makedon krallığı, Helenistik diadochoi).
>
> **KRİTİK KURAL:** Antik Yunan ≠ tek krallık, ≠ tek ulusal ordu. Klasik “Yunanistan” = yüzlerce *polis* + ethnos-ligler + koloniler; sonra **Makedon monarşisi**; sonra **Helenistik diadochoi** krallıkları. Bunlar dil, tanrılar (yerel varyantlarla) ve rekabetçi onur kültürü paylaşır; **tek taht / tek TO&E değildir**.
>
> **Mycenaean** = prolog (ayrı siyasi dil: *wanax*, Linear B). **Homeros ≠ Geç Bronz Çağı (LBA) belgesi** — epik edebiyat, arşiv değil. Percy Jackson / *300* filmi = **FOLK**.
>
> Her bölümde **"Oyunda Nasıl Kullanılır"** notları vardır. Ölçülmüş istihkâm **ARCH**; Herodotos / Thukydides / Ksenophon vb. **LIT** (önyargı bayraklı); yazıtlar **INSCR**; modern sentez **MOD**.
>
> **Eşlikçiler:** `ANCIENT-GREEK-MILITARY-UNITS-AND-TACTICS.md`, `ANCIENT-GREEK-FORTIFICATIONS-AND-DEFENCE.md`, `ANCIENT-GREEK-TOWER-DEFENCE-RESEARCH.md`.

## 0. ÇİFT KEEP + HIZLI TAVSİYE

| Rol | Site / sistem | Neden |
|---|---|---|
| **İdeoloji / marka keep** | **Atina Akropolisi** | Küresel tanınırlık; Propylaia kapı dramı; Parthenon/Erekhtheion ideoloji; Mycenaean derin zaman; Klepsydra / Mycenaean çeşme kuşatma suyu **[ARCH][LIT]** |
| **Askeri kale sistemi** | **Long Walls koridoru + Atina–Pire–Munykhia** | Yunan’ın istihkâm stratejisine özgün katkısı; km ölçeğinde ölçülmüş geometri; 404/393 kampanya vuruşları; donanma bağlantısı **[LIT][ARCH][MOD]** |
| Erken akt | **Mykenai / Tiryns** siklopean | Bronz çağ citadel; Aslan Kapısı; galerili duvar |
| Alternatif haritalar | Messene ~9 km; Syrakusa Euryalos; Thermopylai geçit; Kadmea; Klasik Sparta açık kent | Aşağı §1.6 |

**Neden çift keep?** Akropolis yalnız “kale kulesi” değil: **kutsal kaya + hazine/ideoloji + son sığınak**. Long Walls ise Atina’yı karada olsa da **denizle bağlanmış tahkimli yarımada** yapan askeri sistemdir (**LIT** Thukydides Perikles stratejisi). Çin Weiyang (saray ideoloji) + wengcheng (askeri kapı) çiftine paralel: burada **Akropolis = marka / Athena keep**, **Long Walls–Pire = askeri ada-kale**.

**Varsayılan eşleştirme:** **Akropolis (kutsal) + Long Walls / Pire sistemi (askeri)**.

**Oyunda Nasıl Kullanılır:** Hub dünya = Akropolis dikey arena (batı ramp → Propylaia → tapınaklar). Stratejik kampanya haritası = Long Walls koridor + Pire limanları. Prolog = Mykenai/Tiryns. Saf sur-kule vitrini = Messene. Topçu/hendek = Euryalos. Dar geçit = Thermopylai. Doktrin-anti-masonry = Klasik Sparta.

#### Genişlik / yükseklik — ikincil sentez (kalite bayrağı)

**Tasarımcı için kaynak kalitesi:**

## 32. TASARIMCI TEK SAYFA — STRONGEST VS WEAKEST

**En güçlü:** Varoluşsal koalisyon tutulduğunda (480–479); haraç + trireme + Long Walls hizalandığında (Atina orta 5.); doktrin markaya karşı yenilik yaptığında (Leuctra); Makedon birleşik silah + kuşatma lojistiği kızdığında (Philippos/İskender); Helenistik hazineler topçu/fil finanse ettiğinde.

**En zayıf:** Stasis kapıları açtığında; Sicilya ölçeği aşırı uzanma filoyu yaktığında; Hellespontos tahıl boğazı kesildiğinde (405–404); kırılgan Sparta yurttaş çekirdeği Thebai reformuna çarptığında; Khaironeia polis koalisyonlarının krallık sistemleriyle eşleşemediğini kanıtladığında; Diadochoi fethi parçaladığında; Roma ligleri ve falanksları aştığında (168–146).

**Kampanya omurga hatırlatması:** Mycenaean prolog → Pers Savaşları koalisyon → Altın Çağ Long Walls → Peloponnesos çöküş → Thebai/Makedon menteşe → Helenistik kuşatma çağı — **her akt polis, lig veya krallık etiketli**, asla “tek Yunan kralı” fantezisi değil.
