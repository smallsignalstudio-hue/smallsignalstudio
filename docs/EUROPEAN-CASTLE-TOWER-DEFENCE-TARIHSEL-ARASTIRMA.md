# AVRUPA KALESİ TOWER DEFENCE — Kapsamlı Tarihsel Araştırma Dokümanı

> Bu doküman, "European Castle / Concentric Keep Tower Defence" (veya "Norman–Angevin–Edwardian / Haçlı Kale Tower Defence") oyunu için toplanan tarihsel, arkeolojik, askerî ve ideolojik malzemeyi içerir. Babil, Roma, Pers, Mısır, **Çin**, **Maya–Mexica**, **Viking** ve **Antik Yunan** araştırmalarıyla **aynı formatta** ve **Çin TD Türkçe raporundan bilinçli olarak daha derin** hazırlanmıştır (çok tiyatro: Norman fetih ağı, Outremer / Haçlı devletleri, Capetian–Plantagenet taş yarışı, Edwardian Galler demir halka, Yüz Yıl Savaşı kuşatma ekonomisi, hafif Roses, barut coda).
>
> **KRİTİK KURAL:** Ortaçağ Batı/Orta Avrupa ≠ tek krallık, ≠ tek “Hıristiyanlık civ” ordusu. ~**1000–1500** Latin Hıristiyan bölgesi = Norman / Capetian / Angevin–Plantagenet / Valois–Lancastrian / İmparatorluk sınır kaleleri / İber Hıristiyan uçları (hafif) / **Outremer** Haçlı devletleri — ortak semboller (Latin ritüel, şövalyelik dili), **birbirine savaşan** siyasi tiyatrolar. Outremer ≠ Galler ≠ Gascony ≠ Île-de-France — sessizce birleştirme.
>
> **Çift keep (zorunlu):** **Beaumaris** (Edwardian eşmerkezli diyagram) + **Krak des Chevaliers** (Haçlı fazlı eşmerkezli vitrin) + **jenerik eşmerkezli gramer**. Köprü düğümü: **Château Gaillard**. Erken: motte-bailey → taş donjon (White Tower sınıfı).
>
> **Hard myths:** **Kaynayan yağ varsayılan savunma** = **FOLK** / aşırı oynanmış; **11. yy köylüsünde tam plate** = **FOLK**; **garnizon = saha ordusu** = yanlış; **barut** = uzun eğri coda, tek yıl değil. Şövalye romansı = **LIT/FOLK** skin; kutsal lazer yok.

### 3.2 Perde, mural kule, kapıevi, barbican
- **Perde (curtain):** Kuleleri bağlayan sürekli enceinte. Eşmerkezli şemalarda iç perdeler sıkça **dıştan yüksek** — her iki sur eşzamanlı ateş edebilir **[ARCH][MOD]**.
- **Mural kuleler:** Çıkıntılı (kare → yuvarlak / D-plan); flanking ateş; ölü açı reddi. Yuvarlak formlar mayın / topçuya kare köşelerden daha iyi direnir **[MOD]**.
- **Kapıevi:** Birincil saldırı mıknatısı. İkiz kuleli; sıralı kapılar, portcullis’ler, üst murder-hole’lar. Harlech ikiz kapıevi (~**80 × 54 ft** ikincil sentezlerde; çoklu portcullis) **[ARCH][MOD]**.
- **Barbican:** Ana kapıya yaklaşımı kontrol eden **outwork** — saldırganı açık, açılı veya çatılı kill koridorundan geçirir. Beaumaris güney kapısına **1306**’dan barbican ekleme Cadw/WH sentezlerinde **[ARCH]**. Krak güney yaklaşımı hendek + üçgen barbican mantığı **[ARCH]**.

| Bileşen | Savaş işi | Başarısızlık modu |
|---|---|---|
| Perde | Sürekli duvar HP; wall-walk okçu track | Breach / merdiven / mayın |
| Mural kule | Flank buff; yerel strongpoint | Perde kırılınca izolasyon |
| Kapıevi | Boss kapı; çok aşamalı kilit | Portcullis yakma / sap / ihanet |
| Barbican | Dış filtre; pathing zorlar | Ele geçirme → saldırgan staging |

### 3.3 Hoarding / brattice / machicolation / putlog
- **Putlog delikleri:** Perde duvarlarda kare soket sıraları — kaybolmuş **timber hoarding** arkeolojisi **[ARCH]**.
- **Hoarding:** Dışarı taşan ahşap galeri; taş düşürme; duvar ayağını örtme; **ateşe karşı zayıf** **[CHR][ARCH][MOD]**.
- **Machicolation:** Taş kalıcı düşürme galerisi; Gaillard’da Batı’da erken örnekler tartışılır (Haçlı etkisi argümanı) **[MOD]**.
