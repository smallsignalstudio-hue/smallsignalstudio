10 · Say out loud

Q: How does GC work?

Objects on heap. Roots → reachable = live. Rest = garbage. Young dies in Eden cheaply; long-lived promote to Old. Prod: allocation + leaks → measure → then tune.

Q: Which GC?

Services → G1. Batch → Parallel. Proven GC-broken p99 (21+) → ZGC. Watch Serial on tiny pods.

Q: Frequent Full GC?

G1 Full GC = alarm. Log: humongous / to-space / late mark. Also dump for leak.

Q: Optimize GC?

Mechanism → trade-off → measure (log/JFR/MAT) → decide from data. Cut allocation first.
wall line: Mids recite flags. Seniors measure first, then decide.
